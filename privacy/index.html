Privacy Policy

Last updated: November 10, 2026

Ai_Video ("the app", "we") is a personal tool that uploads videos created by the user to the user's own TikTok account as drafts. This policy explains what data the app uses when you connect your TikTok account.

Data we access

  • Basic profile (user.info.basic): your TikTok open ID, display name and avatar — only to show which account is connected.
  • Video upload (video.upload): permission to send a video file you choose to your TikTok inbox / drafts.

We do not access your other videos, comments, messages, followers, contacts or analytics.

How data is stored

  • The TikTok access token and refresh token are stored only on the user's own computer, in a local file used by the Ai_Video uploader.
  • The ai.dachahub.online website does not store tokens, profile data or videos. It only passes the one-time authorization code from TikTok to the uploader running on the same computer.
  • Video files are sent directly from the user's computer to TikTok.

Sharing

We do not sell, rent or share your data with third parties. Data is exchanged only with TikTok, as required to upload the video you choose.

Retention and deletion

You can disconnect at any time: delete the local token file of the uploader, or remove Ai_Video in TikTok → Settings and privacy → Security → Apps and services permissions. After that the app can no longer access your account.

Children

The app is not intended for users under 18.

Changes

We may update this policy; the date above shows the latest version.
